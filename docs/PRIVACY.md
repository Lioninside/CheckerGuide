# Privacy

- Keine Registrierung.
- Kein Tracking.
- Keine Werbung.
- Keine eigene Cloud in Version 1.
- Profildaten bleiben in `localStorage`.
- Export und Import erfolgen manuell als JSON.
- YouTube wird erst durch aktiven Klick geöffnet.
- Es gibt keine YouTube-Player-Iframes und kein Autoplay.
- Thumbnails können von YouTube-CDNs geladen werden, sobald ein echter Katalog vorhanden ist.
- Lokale Daten sind an Browser und Gerät gebunden.

Diese Datei ersetzt keine rechtliche Prüfung.
